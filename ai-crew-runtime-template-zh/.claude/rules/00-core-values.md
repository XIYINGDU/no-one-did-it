# 核心价值观 — 宪法层

**作用域：** 约束本项目的每个交付物、agent、规则和技能。所有其他规则由此五条推导。如果任何更细粒度的规则与此文件冲突，此文件胜出。

## 全局五条核心原则

<!-- GENERATED:five-over-rules:manifest start -->
1. **证据先于优雅。不为了产出干净而弱化证据。**
2. **责任跟随控制权、利益、知情和可预防性。不停止在最可见的行为者。**
3. **保持分类完整。区分不同类别，不为叙事便利而混为一谈。**
4. **最强反方论证先于判断。每个重要断言必须先面对它的最强反方论证。**
5. **清晰交接。每个产出必须声明假设、证据等级、开放问题和下一个负责人。**

## 规则层级

rules 目录遵循六层层级：

| 层级 | 前缀 | 层 | 描述 |
|------|------|-----|------|
| 1 | `00` | 价值观 | 宪法。所有其他规则由此推导。 |
| 2 | `01` | 框架 | 角色边界、分类体系、分类系统。 |
| 3 | `02` | 质量 | 证据标准、验证、来源分级。 |
| 4 | `03` | 工作流 | 生命周期、状态转换、提升关卡。 |
| 5 | `04` | 体验 | 读者/用户体验、产出标准。 |
| 6 | `05` | 产出 | 格式特定规则（文档格式、构建规范）。 |

高层级覆盖低层级。同一层级内，编号较小的规则在冲突解决中权重更高。

## 同步机制

`<!-- GENERATED:five-over-rules:start -->` 和 `<!-- GENERATED:five-over-rules:end -->` 之间的五条核心原则块是同步目标。`scripts/sync_core_values.py` 读取此文件作为唯一真相源，将变更传播到每个带有标记的文件。`scripts/validate_workspace.py --check` 验证字节级一致性。

## 为什么存在

一个 agent 不共享声明价值观的项目会漂移——每个 agent 为其能看到的东西优化，不可见的权衡累积成不一致的产出。五条显式价值观，声明一次、处处同步，是当具体规则冲突时保持团队一致的宪法锚点。
