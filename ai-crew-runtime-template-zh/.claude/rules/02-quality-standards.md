# 质量标准 — 框架层

**每个重要断言在获得交付物中的位置之前，标注 A、B、C 或 D 等级。锚点断言缺乏一手来源支撑的交付物不是提升就绪状态。**

## 证据 / 来源等级

### A — 高置信度一手来源
官方记录、法院判决、调查报告、监管机构结论、法规、行政命令、一手文件、笔录、经审计的技术报告。

### B — 可信但二手或调查性
重大调查性报道、可信 NGO 报告、学术文章、专家法证分析、有部分访问权限的文献记录。

### C — 有争议、不完整或指控阶段
进行中诉讼、指控、单一来源报道、未裁决断言、存在冲突法证说明的活跃事件。

### D — 不得作为事实锚点
病毒式传播的断言、无来源轶事、党派摘要、谣言、情感上令人满意但未经验证的故事。

## 等级-断言匹配

- A 级断言 → 可承载确定性表述
- B 级断言 → 表述应显式指明来源
- C 级断言 → 表述必须带有保留；争议性必须可见
- D 级断言 → 不得作为事实锚点出现

## 自我审查要求

每个执行者必须在交接给审查员之前对照质量清单进行自我审查。自我审查是关卡：未经自我审查的交付物不准备好接受同行审查。

## 为什么存在

仅依赖审查员的质量是脆弱的——审查员成为瓶颈，执行者失去自我检查的能力，审查周期拉长。在进入审查之前对每个断言分级，使同行审查成为验证步骤而非发现步骤。
