# Restructure plan — EPUB + PDF, 2026-05-31

> Generated by the `epub-pdf-restructure-investigation` workflow on 2026-05-31. Six parallel investigation streams plus a synthesis pass. Status: **awaiting decisions in §9 before execution begins.**

## 0. Overview

Coordinated cross-cutting changes to *No One Did It* build pipelines: (1) **remove 13 chapter-cover plates** from both EPUB and print PDF, restoring the original typographic chapter opener; (2) **embed 12 diagram PNGs** from `book/evidence/diagrams/proofs/` as figures in chapters 02–13, keeping existing markdown tables alongside for audio-survivability; (3) **fix heading top margins** (h2/h3/h4) in both `kdp.css` and `printCss()` so demoted-bold h4 headings stop reading as flush-against-prose; (4) **harden the print page-count cascade** so interior → cover spine math survives the page-count change automatically. Deliverables: new `dist/no-one-did-it.epub` (~25 MB after PNG recompression, epubcheck-clean, Kindle Previewer-clean) and new `dist/no-one-did-it-interior.pdf` (~441–448 pp, every chapter page numbered) with matching `dist/no-one-did-it-cover.pdf` whose spine width is recomputed from the measured interior page count.

## 1. Ordering of changes

1. **Open decisions resolved first (§9).** No code touched until user picks: spine schema option, keep-tables-vs-replace, ch-13 inclusion, ch-08/ch-11 pending-data path, PNG recompression strategy, running-header policy.
2. **Heading-margin CSS fix lands first, isolated.** Independent of cover and figure work; lets us prove CSS edits don't regress before stacking format-shape changes.
3. **Pipeline hardening (`pipeline.mjs` pdfinfo guard) lands second.** Trivial one-line change; protects every subsequent rebuild.
4. **Chapter-cover removal lands third (one commit, both formats).** Cover removal alone is the bigger delta (−13 pp interior); should be verified in isolation. Print pipeline requires the `print-pdf-finalize.py` `range(start, end+1)` fix in the same commit so chapter page 1 is numbered.
5. **CSS pruning for chapter-cover dead code lands fourth.** Deferred one build cycle as rollback insurance.
6. **Figure embedding lands fifth, in two phases.** 5a: assembler/CSS infrastructure. 5b: per-chapter figure insertion (11 chapters if ch-08/ch-11 gated; 12 if cleared).
7. **PNG recompression lands sixth.** Optimization, not correctness.
8. **KDP listing-pack documentation lands last.** Page count, EPUB size, spine width not known until final post-rebuild measurements.

## 3. EPUB build workflow

```bash
cd .

python3 pipelines/epub/assemble_v6_manuscript.py
python3 pipelines/epub/build_kdp_epub.py
python3 pipelines/epub/validate_kdp_epub.py
# Optional: kindlepreviewer dist/no-one-did-it.epub -convert -output dist/previewer-out/

```

Spot-check: cover renders; TOC navigates; footnote pop-up works; part divider plates render; embedded figures + figcaption visible; no raw `[CITE:]` / `[^N]` / HTML comment markers leak; h4 spacing visible in ch-02 / ch-06.

## 4. PDF build workflow

```bash
cd .

# Baseline
pdfinfo dist/no-one-did-it-interior.pdf | grep Pages

# Build (auto-cascade interior → cover spine via measured pdfinfo)
cd pipelines/print && node pipeline.mjs && cd ../..

# Verify
NEW_PAGES=$(pdfinfo dist/no-one-did-it-interior.pdf | awk '/^Pages:/{print $2}')
python3 -c "print(f'expected spine: {$NEW_PAGES * 0.0025:.4f}\" cream')"
pdfinfo dist/no-one-did-it-cover.pdf | grep "Page size"
# Cover total width should equal: 2*0.125 (bleed) + 2*6.0 (trim) + expected_spine
```

Spot-check: TOC folio for 3 random chapters matches actual chapter start page; chapter page 1 carries folio AND running header; embedded figures fit the 4.875" content column with figcaption underneath; h4 headings have visible top spacing.

## 6. Risks

1. **`print-pdf-finalize.py:127` fix forgotten** — every chapter page 1 ships without folio. Silent. Verification gate in §5.
2. **pdfinfo silent fallback** — cover built for 446 pp on 441-pp interior; KDP rejects at upload. Mitigated by step-3 hardening.
3. **Spine schema choice forecloses extension** — recommendation (b) preserves extensibility.
4. **EPUB delivery surcharge at 70% royalty** — +$1.98/sale before recompression. Mitigated by pngquant ≤ 6 MB target.
5. **ch-11 SOX column unverified** — see decision §9.4.
6. **ch-08 PENDING overlay on PNG** — see decision §9.5.
7. **PNG figure path resolution at PDF render time** — Playwright resolves from `out/sections/`. Mitigated by `absolutizeImagePaths()` helper.
8. **Kindle TTS reads alt as flat string** — 30+ cell figures become unintelligible. Mitigated by keeping tables alongside images.
9. **CSS shorthand zeroing h4 margin** — future contributor adds `margin: 0 ...` shorthand. Mitigated by longhand declarations + explicit trap comment.
10. **ch-13 crosswalk 8×6 grid illegibility on 6" Kindle** — fallback options: higher DPI re-render, or split into two stacked 4×6 images.
11. **Print PDF page-count growth from figures** — worst +12, likely +3 to +6. Auto-cascade handles cover spine.
