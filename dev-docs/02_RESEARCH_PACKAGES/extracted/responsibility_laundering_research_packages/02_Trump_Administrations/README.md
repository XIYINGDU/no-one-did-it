# Trump Administrations Package

## Files
- `case_matrix.csv` — structured case bank.
- `case_cards.md` — draft-friendly narrative cards.
- `source_ledger.csv` — source leads and primary documents.
- `narrative_weaving_notes.md` — suggested book placement and motifs.

## Use rule
Use A-grade cases as anchors, B-grade cases as supporting examples, and C-grade/live cases as leads requiring current verification.
