# Content Audit — Manual Classification of Surviving Flags

After patching the audit tool (gzip decompression, interstitial detection, max(recall,precision) similarity, big-PDF handling, increased extraction window) the flagged set fell from 191 to 63. Inspecting each surviving record, the 63 break down as follows.

## Method

For each card the source.title (claim) was compared against the live and Wayback-snapshot identity of the URL. A "real defect" is a case where the URL serves a document or page that does not anchor the card's claim — the Ross-memo defect class.  A "false positive" is a case where the URL does anchor the claim but the token-overlap similarity is depressed by legal-citation noise in the card title (docket numbers, court abbreviations, dates as numbers, court-of-appeals counts) that does not appear on the press release / opinion / news article.
