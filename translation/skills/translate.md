# 翻译 Skill

**使用者：** Translator
**版本：** 1.0.0（试点阶段，随第 1 章实践迭代）

## 通过标准（四条全满足才算通过）

### 1. 准确度
每句话的核心信息在中文中存活。不增不减不扭曲。
- 原文的每个事实陈述在译文中可追溯
- 原文的限定词/模糊词（probably, arguably, appears to）必须在译文中保留
- 原文的道德重量（severe, precise, cold）在译文中不变

### 2. 术语合规
所有术语使用 `glossary.yml` 中的译法。零例外。
- `forbidden` 字段中的译法绝不使用
- 术语首次出现时保留原文并括号注中文（如 "pharmakos（替罪人）"）
- 后续出现时直接使用中文术语

### 3. 语域存活
原文的叙事热度/分析冷度/道德转折短句在中文中可感知。
- 叙事段落：具体、动词有力、场景感
- 分析段落：简短、精确、不煽情
- 道德转折句：保持短句，不拉长，不加解释性形容词

### 4. 引用完整
- `[CITE: slug]` 标记原样保留
- 脚注 `[^N]` 编号原样保留
- `>` 引用块翻译为中文，脚注保留英文
- HTML 标签（`<sup>` 等）原样保留

## 失败标准（触发退回修复）

- 用优美中文替换了原文含义（改写而非翻译）
- 临时发明术语翻译（未查术语表）
- 原文的道德重量在中文中消失（冷峻变温情、精确变模糊）
- 跳过难句或缩写长句导致信息丢失
- 添加原文没有的解释或评价

## 冲突处理

1. **术语表译法在上下文中不自然。**
   仍然使用术语表译法。在翻译笔记中标注 `[TERM-NOTE: 第X行 "<术语>" 在此上下文中略显生硬，建议 Glossary Master 审查]`

2. **原文有歧义。**
   保留歧义，不做消歧翻译。标注 `[AMBIGUOUS: 原文此处有歧义，可能的两种理解为...]`

3. **英文长句在中文中无法阅读。**
   允许拆分，但标注 `[SPLIT: 原文第X行为一个句子，拆分为X个中文句]`。不改变信息顺序。不合并相邻句子。

4. **专有名词没有公认中文译法。**
   保留原文，标注 `[TRANS-LOAN: "<词>" 暂无公认中文译法，保留原文。建议 Glossary Master 裁决]`

5. **引用中包含非英语。**
   非英语部分（德语、法语、拉丁语、希伯来语等）以斜体保留。首次出现时括号注中文翻译。

## 升级条件

- 术语表译法在 3 处以上不自然 → 升级给 Glossary Master
- 原文本身的含义不清或逻辑断裂 → 升级给 Translation Director
- 引用标记 `[CITE:]` 与上下文不匹配 → 升级给 Translation Director
- 连续 3 个段落存在歧义需要消歧判断 → 升级给 Translation Director

## 输出格式

每个翻译段以对照格式产出：

```markdown
### [段落编号/章节]

**原文：**
> ...

**译文：**
...

**翻译笔记：**
- [TERM-NOTE] / [AMBIGUOUS] / [SPLIT] / [TRANS-LOAN] 等标注
- 需要 Reviewer 特别关注的地方
```

## 翻译节奏检查清单（译者自检）

在提交审核前，译者必须逐项自检：

- [ ] 每个事实陈述在译文中可追溯到原文
- [ ] 每个术语使用了 glossary.yml 的译法
- [ ] 没有添加原文没有的解释
- [ ] 每个 `[CITE:]` 和脚注标记原样保留
- [ ] 道德转折句保持了短句形式
- [ ] 长句拆分已标注
- [ ] 歧义处已标注而非消歧
