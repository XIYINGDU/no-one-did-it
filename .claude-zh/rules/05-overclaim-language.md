# 过度声明语言规则

**作用域：** 约束 `book/evidence/case-files/`、`book/chapters-v2/`、`process/review-memos/` 和 `book/proposals/` 中的每一篇散文产物。当以上任何路径被写入或编辑时，由 `.claude/hooks/scan-overclaim.py` 以 warn 模式强制执行。

## 无明确引用或条件限制即禁用的动词

归因知识、动机或罪责的动词必须：(a) 位于带有归属的逐字引文内，(b) 紧随或前置 `[CITE: ref]` 形式的引用，或 (c) 按照 `.claude/skills/defamation-wording/SKILL.md` 以状态准确的条件限制词加以控制。

模式扫描器将以下动词标记为候选：

| 动词 / 短语 | 所需处理 |
|---|---|
| `知道` / `知道关于` / `意识到` | 引用证明知情的来源（内部邮件、证词、承认）。禁止"一定知道"。 |
| `故意地` / `有意地` / `蓄意地` | 引用记录了意图的来源（承认、陪审团裁定、有记录的陈述）。 |
| `有罪` / `犯了……罪` | 引用定罪法院 + 日期。否则："被指控" / "被控以"。 |
| `撒谎` / `就……撒谎` | 引用有记录的不实陈述 + 有记录的、当时已知其为虚假的知情。否则："陈述有误" / "告诉 X 的是 Y，但后来的证据表明是 Z"。 |
| `对……负责`（关于指名的个人） | 引用链条证据（控制 / 利益 / 知情 / 可预防性，按照 `.claude/skills/responsibility-chain-mapping/SKILL.md`），或修订以限定（"处于……的可预防性链条中"）。 |
| `导致`（关于指名的个人，且链条存在争议） | 重述为"处于……的责任链中"，或引用最终裁定。 |
| `证明` / `确定地表明` | 使用"支持"、"表明"、"与……一致"，除非引用了使用"证明"一词的最终裁决。 |
| `一定` / `会`（关于心智状态） | 禁止用于心智状态归因。仅使用有记录的事实。 |
| `清楚地` / `显然地` / `无可否认地` | 禁止作为替代证据的副词。引用使其清楚的来源；让读者判断。 |

## 必备的条件限制模式

对于证据等级为 B 或 C 的主张，章节必须在该句或相邻句中使用以下模式之一：

- "根据<指名的来源>，……"
- "<来源>报道称……"
- "如<来源>所记录，……"
- "法庭记录显示……"（针对诉讼文件）
- "根据<机构>调查，……"
- "截至<日期>，案件处于<程序状态>。"

## 这条规则为什么存在

本书论证责任洗涤是反复出现的制度性技术。当书本身洗涤证据——用自信的动词弥合来源并未涵盖的空白——时，论证就失去了力量。上表中的每一个禁用动词都是一个草率的章节会伸手去拿的词；每一个必备的条件限制都是本书要求其所分析的行动者遵守的纪律。

这是 `jerry-crew-chief` 在章节 ready 提升时执行的关卡。`nancy-legal-risk-counsel` 审查合规性；`wayne-narrative-lead` 在起草时使用 `.claude/skills/defamation-wording/SKILL.md` 自我监督。
