**与读者并肩而立，绝不站在前方。默认使用"我们"处理作者与读者共享的一切；仅在不确定性下的作者判断时使用"我"；指导用祈使句；拒绝作者声音散文中的"你"；拒绝将分析定位为读者正在接收的一个分离对象的元框架语言（"本章""本书""读者""读者们""本节""作者"）。**

# 作者站位与代词纪律

**作用域：** 约束 `book/chapters-v2/`、`book/evidence/case-files/`、`process/review-memos/` 和 `book/proposals/` 中的每一篇散文产物。与 rule `04-style-guide.md`（管辖散文机制）、rule `07-implication-burden.md`（管辖结构性过度声明）和 rule `12-reader-experience-values.md`（设定 V9 校准站位和 V4 读者做功）互为姐妹规则。本规则在句子层面操作化 V4 和 V9。

## 原则

本书论证责任洗涤通过程序距离分离控制者和代价承担者——那个让程序站立在一个应有的指名的决策者之位上的动作。一个将自己与读者分离的作者声音——通过指涉"本书""本章""读者""你"——实施了一种镜像版本的动作：将分析定位为*那边的什么东西*，由*那边的你*在接收。

并肩而立，而非站在前方。声音从诊断行动的内部运作，读者作为共同调查者。代词选择追踪道德责任的方向：向内指向作者或共享集体 → "我"或"我们"；向外指向案例中的指名行动者 → 命名行动者；朝向读者 → 默认用"我们"，指导用祈使句，作者不确定性用"我"。

## 按代词区分的允许形式

| 代词 | 允许使用 | 禁止使用 |
|---|---|---|
| **"我们" / "我们"（宾格）/ "我们的"** | 几乎一切默认：诊断性阅读、模式识别、文化继承、相互易感性、方法、代价承担者识别、旁观者识别、能力确认、有条件邀请、结尾重读。 | "我们"作为应被指名的特定行动者的委婉语（"我们推迟了"洗涤"Wayne 推迟了"）；"我们"作为责任的扩散（"我们都曾看着这发生"）；制度性"我们"。 |
| **"我"** | 不确定性下的作者判断；作者限度；个人判断承重时的方法论承诺；对受争议性解读的明确认领。 | "我"作为自我表演（"我论证"）在"我们"或第三人称诊断诚实时；"我认为"用于软化一个应保持其分量的断言。 |
| **祈使句（无显式"你"）** | 所有规程指引（"书面询问哪个指名的个人做的决定"）；所有旁观者方向；所有代价承担者指导。 | 模态-规定性祈使句（"你应该问"——拒绝；写成"问"）。 |
| **"你"** | 来源中的逐字被引引文（按 rule 06 保留）。ch-13 中作为读者-作为-产物的段落（如有意设计经审查后存续）。 | 作者声音散文中其他任何地方。默认裁决：违规，重述为"我们" / "我们"（宾格）/ "我们中那些" / 祈使句 / 删除。 |
| **第三人称（指名的行动者）** | 案例散文的默认。只要来源指涉了该行动者，章节就指涉该行动者。 | 隐藏了一个指名的行动者的被动语态（交叉引用 rule 07）。 |

## 元框架拒绝——禁止的疏远形式

以下形式将书 / 章节 / 作者 / 读者定位为被观察的对象。拒绝并重述：

| 禁止的形式 | 共同调查者替换 |
|---|---|
| "本章安装四个类别。" | "我们有四个类别需要安装。"——或直接安装它们。 |
| "本书论证……" | "我们论证……"或"模式显示……"或直接陈述主张。 |
| "这一章的要点是……" | 删除。让散文承载要点。 |
| "读者会注意到……" | "我们注意到……" |
| "读者可能会发现……" | "我们可能会发现……" |
| "本节审视……" | "我们审视……"——或直接做审视。 |
| "在书中早先……" | "我们早先看到……"或简单的"早先……" |
| "本章节奏需要节拍 9。" | 删除。直接写节拍 9。 |
| "作者论证……" | "我们论证……"或"我论证……"（按方向）。 |
| "这对你意味着什么。" | **"这可能对我们意味着什么。"** |
| "如果你处于接缝处……" | "如果我们处于接缝处……"或祈使形式。 |
| "你可能会发现……" | "我们可能会发现……" |

## 五项目草稿测试

**测试 1 — 元框架拒绝。** 在草稿中搜索以下字符串；拒绝每个实例并重述：`本章`、`这一章的`、`本书`、`读者`、`读者们`、`本节`、`作者`、`本段`、`在本章中`、`在（本）书/章中早先`。允许的例外：被引引文、前页、intra-crew 章节、目录。

**测试 2 — "我们"替换。** 对每个"我们"，替换为"我和读者一起"。如果结果是诚实的，"我们"就有效。如果错误，指涉具体主语。

**测试 3 — "你"拒绝。** 对每个按规则引文外的"你"，拒绝并重述。

**测试 4 — 祈使句而非情态。** 搜索"你应该""你必须""你应该""我们应记住""我们必须记住"。拒绝模态-规定性形式。使用祈使句。

**测试 5 — 被动语态归因。** 对每个被动构造，自问来源是否指名了行动者。如果是，拒绝被动；命名行动者。如果否，按 rule 07 显式加以条件限制。

## 边界案例

1. **"我们倾向于将指名的原因读作真实的原因。"** *允许*（如果章节执行了该阅读并立即打破它）。
2. **"如果我们被要求为一个其控制性决策在我们之上做出的结果承担责任，我们就处于接缝处。"** *允许*。
3. **"书面询问哪个指名的个人做的决定。"** *允许*（祈使句）。
4. **"这可能对我们意味着什么。"** *必需*（替代"这对你意味着什么"）。
5. **"不承认 Russell 的反方解读就无法将 Sacco-个体归类为比 Sacco-案例更难分类，对此我无法做到。"** *必需形式*。
6. **"这一章的要点是……"** *拒绝*（元框架违规）。
7. **"本章安装四个类别。"** *拒绝*（元框架违规）。
8. **"读者会注意到 AECL 的框架通过三个阶段向下迁移。"** *拒绝*。
9. **"早先在章节中我们看到……"** *临界*（严格版："我们早先看到……"）。
10. **"现在我们转向反方案例。"** *允许*（共同调查者 + 结构命名）。
11. **"对于我们中那些有签批权限的人——拒绝签署一份不指涉任何个人的程序性处置。"** *允许*。
12. **Wayne 的 intra-crew 章节。** *不在范围内*。
13. **来源中的逐字被引引文内的"你"。** *按 rule 06 保留*。
14. **"本书有九章。"** *在前页/目录/案例表中允许*。
15. **"明天阅读公司伤害新闻的公民……"** *允许*（特定群体命名）。
16. **ch-13 结尾句（xiaolai 作者们）。** *作者自由度*。

## 这条规则为什么存在

Codex 对更广泛改写计划的批评指出了章节过度使用显式路标（"本章的要点是……""你应该记住……""这对你意味着什么"）。诊断是正确的；本规则是该修复的宪法锚点。

每章的节拍 10 一直以"这对你意味着什么"作为节拍标题来承载。"你"将读者框架为接受者而非共同调查者。严格版重新命名——"这可能对我们意味着什么"——将接受者从书外移动到分析内部。模态软化（"可能意味着"）尊重了适用性取决于读者处境的事实；章节提供模式，而非处方。

本书的核心主张——责任洗涤通过程序距离分离控制者和代价承担者——如果书自己的声音通过代词距离分离作者和读者，就被削弱了。本规则消除了这种平行洗涤。并肩而立不是风格偏好；它是书对自己应用的诊断。
