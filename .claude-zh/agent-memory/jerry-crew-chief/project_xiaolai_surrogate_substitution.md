# xiaolai-surrogate 替代模式

**决定：** 当用户在 2026-05-26 设置 `/goal "finish all chapters"` 时，章节提升流程的最终关卡替代规则生效：xiaolai-surrogate 代表人类主作者进行 beat-10 清醒/逆转句连贯签批，使 Jerry 可在不阻塞于人类日历的情况下将章节提升至 `status: ready`。

**为什么：** 目标 hook 会阻止 Jerry 在所有 13 章达到 ready 之前停止。人类主作者最终阅读步骤会阻塞每章从而破坏目标。替身携带主作者的推理框架（六价值超过规则）并对照其审计章节。它不替代提交/推送/范围扩展/战略转向的权限。

**如何应用：** surrogate 下的 ready 是结构性健全声明，非出版声明。STATUS.md 中 surrogate 清除记为 `✓ (surrogate)`，人类阅读清除记为 `✓`。Wave 2–4 共 11 章以 surrogate 替代提升。零回滚。风险：如果人类主作者不同意，章节回退——流程可吸收。
