手稿中每个行政法案例（AEA/Abrego Garcia、J6 赦免、DOGE、Watergate、Iran-Contra）都指向共和党行政。ch-8 的党派接种装置——在同一政党框架内展示两种不同洗涤形态——是设计上的结构性特征，但使该书暴露于被视作党派选择性。al-Aulaqi OLC 备忘录（民主党行政）被添加作为跨价检查，但它的洗涤形态不同（意见作为工具 vs. 机制作为滥用）——它接种的是洗涤不随党派而变，而非两党同等有罪。差距已标明，未解决——任何未来的冷读者或右倾 blurb 读者会注意到这一点。
