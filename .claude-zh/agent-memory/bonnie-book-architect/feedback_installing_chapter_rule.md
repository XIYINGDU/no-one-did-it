**规则。** 当一章的承重工作是*安装*一个分类（本书中为 ch-2 安装四个类别）时，锚点案例必须为单一类别。跨不同链层合法解读为多个类别的混合案例属于*模式*章（Part II），而非安装章。

**为什么：** 安装章需要干净的锚点，因为读者需要看到明确的案例来安装分类。混合案例模糊了分类边界，使读者无法区分各类别。混合案例在模式章中起作用——安装章需要保持分类标签干净。
