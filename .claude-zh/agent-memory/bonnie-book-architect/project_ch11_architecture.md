ch-11（"让责任跟随控制"）是 Part IV 的开篇论证章。设计-不对称矩阵：单点无责任 vs. 组织分散但控制/知情/利益可映射。四个工作示例：Park（企业高管个人责任）、SOX（合规作为反洗涤装置）、SMCR（英国高级管理人员制度）、Inquiries Act §21 vs. EO 13328 对比。自由意志主义 + 捕获反方以全强度呈现（不是稻草人）。生存者偏差频率让步："这些设计大多未被采用——但我们在此测量的是已采用的设计是否按意图运作，而非采用率。"
