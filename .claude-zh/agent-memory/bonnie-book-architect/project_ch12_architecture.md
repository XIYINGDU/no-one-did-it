三条记录纪律规则：(1) 写下来——记录是洗涤的反面；(2) 保管链——谁在何时接触了记录；(3) 让销毁可见——销毁记录的后果必须可映射。四个记录存续面板：Pentagon Papers、Iran-Contra PROFS 磁带、Hofeller 硬盘、FRA 记录销毁。对手管辖区范围条件：规则仅在记录-公共-归因是争议中的洗涤向量的案例中有效。Vermeule 置换反方在第 1 条规则以强形式呈现——行政权力论证记录约束削弱了总统制，这正是为什么要坚持。
