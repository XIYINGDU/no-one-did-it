当添加跨价/跨党派案例以回应"党派捕获"冷读发现时，在两个轴上加以红队审查：1. 是否读来像象征性平衡/虚假对等？2. 该案例的洗涤机制是否与其所配对的模式 GENUINELY 相同，还是仅仅在政治意义上"对立"？

反党派对称的规则双向切割。为书中每个案例增加另一方案例，如果其洗涤机制匹配且证据等级支撑，是诚实的；如果我们在不同模式的拓扑上强加政治对称，就是和捕捉党派对称同样的罪过。另一方案例如果未通过机制适配测试，不应插入——宁可让模式证明某类洗涤不随党派而变化。
