规范案例文件结合了 `.claude/docs/case-card-template.md` 的字段加上 Bhopal 先例形式。完整字段：Case name/Domain/Dates/Case type + Crisis → Handoff 块。最佳实践：frontmatter 携带 status/case_type/evidence_grade/owner/handoff；正文为围栏文本块中的完整 Crisis 至 Book function。Bhopal 先例建立了避免分类坍缩的形式——每个字段的填充方式使得事实核查者可对照一手来源独立验证每个字段。
