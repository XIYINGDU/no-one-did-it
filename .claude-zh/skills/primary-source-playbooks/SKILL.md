# 一手来源操作手册

<!-- GENERATED:five-over-rules:start -->
1. **Evidence before elegance.** Never improve the story by weakening the evidence.
2. **Responsibility follows control, benefit, knowledge, and preventability.** Do not stop at the most visible actor.
3. **Keep the taxonomy intact.** Distinguish pure scapegoat, partial scapegoat, system/object alibi, and cost-bearing goat.
4. **Steelman before judgment.** Every major claim must face its strongest counterargument before it is asserted.
5. **Handoff cleanly.** Every output must state assumptions, evidence grade, open questions, and next owner.
<!-- GENERATED:five-over-rules:end -->

## 使用方法

识别主导领域，打开对应手册段落，自上而下作业：从该领域最高权威来源开始，当佐证达到章节所需等级时停止。**在穷尽一手来源路径之前不要跳到二手来源。**

## 四领域分层体系

### 历史（Shirley）
- **Tier 1：** 最终法院判决+意见；官方调查报告；监管机构裁定；法规/行政命令。
- **Tier 2：** 经同行评议的学术专著；已出版档案版本（FRUS 等）。
- **Tier 3：** 附有 FOIA 文件的重大调查报道。
- **Tier 4（不用作一手来源）：** Wikipedia；无来源装置的通俗历史。

### 战争/国家策略（Selina）
- **Tier 1：** ICC/ICTY/ICTR/SCSL 逮捕令、控告、判决；UNSC 决议；OHCHR 报告；ICRC 评注；普遍管辖权国家法院判决。
- **Tier 2：** HRW/Amnesty 详细调查；Bellingcat OSINT（有记录监管链）；国家委员会调查。
- **Tier 3：** AP/Reuters/AFP 带驻地记者的通讯稿。
- **Tier 4（不用作一手来源）：** 冲突方新闻稿作为事实；匿名 Telegram 频道。

### AI/技术（Warren）
- **Tier 1：** 模型卡+系统卡（附带日期+Wayback）；预注册基准协议；法院诉讼文件；监管机构文件；官方安全报告。
- **Tier 2：** 独立基准论文（METR/Apollo）；机械可解释性出版物；已建立的政策研究（Stanford HAI 等）。
- **Tier 3：** Wired/MIT Tech Review 等附指明来源的报道。
- **Tier 4（不用作一手来源）：** 营销帖文；Twitter/X 讨论。

### 公法/政治（Loki）
- **Tier 1：** 联邦法院案卷（PACER/CourtListener）；行政命令（Federal Register 引用）；GAO/IG/CRS 报告；国会记录。
- **Tier 2：** Just Security/Lawfare/SCOTUSblog 等专家法律评论。
- **Tier 3：** 附记录备忘录的 AP/Reuters/NYT/WaPo 政治报道。
- **Tier 4（不用作一手来源）：** 有线新闻评论；匿名账号帖文。

## 产出格式

```text
Claim: / Domain: / Tier 1 source attempted: / Tier 2 source used: / Tier 3 (if any):
Access notes: / Wayback snapshot URL: / Evidence grade: / Handoff:
```
