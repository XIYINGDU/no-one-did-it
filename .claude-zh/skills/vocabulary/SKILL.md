# 责任洗涤书籍——领域词汇

> 本书项目的规范名词和动词集。每个产物名称、散文描述和规则措辞应从此注册表提取。同义词由 `/nlpm:check` 标记，在 R51 启用时由 `/nlpm:score` 惩罚。

## 动词（内部范围）

| 规范动词 | 弃用同义词 |
|---|---|
| `build`（构建） | make, produce, create |
| `audit`（审计） | check, review |
| `draft`（起草） | compose, pen, author, write |
| `revise`（修订） | rewrite, polish, edit |
| `grade`（分级） | rank, score, rate |
| `flag`（标记） | note, warn |
| `gate`（关卡） | block, hold, stop |
| `handoff`（交接） | pass, delegate, transfer |
| `red-team`（红队） | attack, stress-test |
| `fact-check`（事实核查） | verify（针对单项声明） |

## 案例分类名词（不可替换）

| 规范 | 禁用替代 |
|---|---|
| `pure scapegoat`（纯粹替罪羊） | innocent victim, wrongly accused |
| `partial scapegoat`（部分替罪羊） | mostly guilty, lower-level fall guy |
| `system/object alibi`（系统/对象托辞） | procedural cover, system blame |
| `cost-bearing goat`（承受代价的羊） | collateral damage, silent victim |

## 诊断问题名词

`control`（控制）、`benefit`（利益）、`knowledge`（知情）、`preventability`（可预防性）、`record control`（记录控制）、`cost bearer`（代价承担者）——精确措辞，不替换。
