# 读者价值模板

> **目的。** 每章以将章节诊断转化为读者可带入周一早上的东西的段落结尾。本模板强制执行该段落必须包含的内容。

**作用域：** 约束 `book/chapters-v2/` 中的每章。

## 四个读者问题

1. **识别它。** 该洗涤模式在非头条生活中何处出现？指涉读者的工作场所、他们签署的合同、他们消费的新闻框架、他们使用的 AI 工具、他们持有的制度角色中的至少一个。
2. **诊断它。** 警示信号是什么？两到三个可观察的标记表明该模式正在对读者运行。
3. **对它行动。** 读者看到时可以具体做什么？按角色区分：作为代价承担者/候选羊、作为旁观者、作为有权力的制度行动者。
4. **避免成为它。** 读者何时可能被设置为亲自扮演羊？什么信号会警告他们正在被定位为他人洗涤企图中可见的被归责方？

## 通用性黑名单

仅使用以下模式的 beat-10 段落审计关卡失败："保持关注""提出问题""让机构负责""保持警惕""要求透明""阅读细则""凭良心投票""批判性思考"。这些短语不是行动——它们是一个还没有 beat 10 的章节的口头装饰。
