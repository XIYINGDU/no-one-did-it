## 章节概要
- 标题：《When Power Calls Itself the Goat》→《当权力自称山羊》
- 核心概念：反向归责（inversion）— 当权力声称自己是受害者，将制约它的制度机制重新框架为"先前的不公"
- 三个当代案例：2025 年 1 月 6 日赦免令 / DOGE 记录诉讼 / 敌对外侨法援引
- 三个历史回声：水门事件 / 伊朗-康特拉 / al-Aulaqi
- 反洗钱规则句：问责机制不是洗白。把机制称为洗白，本身就是洗白。
- 引用密度：57 个 `<sup>` 内联引用 + 57 条脚注
- 非英语术语：拉丁（per curiam, habeas corpus, ex parte）、西班牙（Tren de Aragua, CECOT, estado de excepción）
