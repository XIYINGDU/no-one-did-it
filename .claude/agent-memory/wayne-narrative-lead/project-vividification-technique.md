A craft technique for the book "No One Did It" that converts abstract phrasings into concrete mental images. Proven in the preface; applied chapter-by-chapter in v4 as a FIND-CANDIDATES-then-rewrite workflow (find phase produces an inventory in `process/plans/image-candidates/`; never rewrite during the find phase).

**Why:** Abstraction is the enemy of an audio-survivable (V10) and earned-not-manufactured (V1) reading. A concrete image the reader can see lands the diagnostic harder than an abstract phrase — but ONLY if the vividness is honest.

**How to apply:** Exactly two safe forms, one forbidden form.

- SAFE FORM 1 — "render the record": replace an abstract phrasing with a concrete detail ALREADY DOCUMENTED in the source record (the actual on-screen error code, the exact number of convictions read in court, the named street). Vividness pulled from the source, never invented. Point at the nearby `[CITE: slug]` / footnote where it's documented, or mark "in the record — Stephen to confirm".
- SAFE FORM 2 — "reader-facing hypothetical": a clearly-hypothetical "this could be us" image, confined to reader-applicability beats. Claims nothing about a real party. Proven preface form: "the form we initialed, drafted by a hand we never met, on grounds we were never shown." (preface line 25)
- FORBIDDEN — invented detail on a real actor/event: trembling hands, inner thoughts, "he must have felt…", invented sensory/weather/room detail not in the record, focalize-then-fact. This is exactly what the book condemns in others (rules 05/06/07; values V1, V8). If a spot wants vividness but only invention would supply it, record it as "abstract-but-no-record-correlate — leave abstract."

**Device economy:** flag generously but mark only 2-4 HIGH per chapter; note where a chapter is ALREADY concretely vivid so we don't pile on and rebuild the monotony v4 is fixing (see [[project-v4-detemplating]]). Vary the image TYPE across candidates.

**Near living actors:** flag "Nancy check" — ch-12 carries live records-litigation content (FRA / DOGE). Render-the-record near a named living actor still needs defamation review.
