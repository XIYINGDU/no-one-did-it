When a cross-valence / cross-party case is added to answer a "partisan capture" cold-reader finding (every case so far is one party), red-team it on TWO axes, not one:

1. The obvious axis: does it read as token balance / false equivalence? (The over-rule against partisan symmetry cuts both ways.)
2. The non-obvious axis: does the added case actually instantiate the chapter's specific structural pattern, or is it force-fit into a shared-shape sentence to complete the roster?

**Why:** the cure for partisan capture must itself be honest, or it reproduces the disease at one remove — claiming a false structural identity to balance the roster is partisan-symmetry-by-assertion. The al-Aulaqi addition to ch-8 (2026-05-28) passed axis 1 strongly (the steelman was *harder* than the existing Republican case per Alan, so it was the opposite of token balance) but failed axis 2 (the synthesis forced it into the wrong laundering shape). See [[project-ch8-two-laundering-shapes]].

**How to apply:** a stronger-than-the-existing steelman is good evidence the addition is NOT token balance — but it does not by itself prove structural fit. Check the "they share one shape" connective sentence against each case independently. Also: "proves"/"the proof" in the book's own voice about its own roster is rule-05 overclaim (a sample from the record supports, it does not prove); push to "supports"/"shows"/"carries."
