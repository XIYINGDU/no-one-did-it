# v4 Device-Economy Budget

Owner: Bonnie / Book Architect / Developmental Editor
Task: Set a finite frequency budget for every recurring analytical device in the book at once, so the crew stops chasing one device-instance per sweep and instead caps each device by design. For every device: full-strength home, compressed-reference chapters, cut/forbidden chapters, and a footnote-safety flag.

## Role boundary

This is a **structural design** artifact. It specifies, per device, where each appears at full strength, where it compresses to a reference, and where it is forbidden — and flags which compressions are footnote-safe versus footnote-risky. It does **not** write prose, re-grade evidence, alter responsibility-chain analysis, change case placement, or touch the case-file dossier. Wayne executes chapter by chapter; Stephen re-runs footnote/cite integrity after each cut; Laura red-teams V1/V3/V5/V8; Nancy re-clears any relocated defamation-adjacent paragraph. The budget is owned here per the sweep's handoff ("Bonnie — decide whether the interception-channel table is owed in every chapter").

## Why a budget, not another instance hunt

Four consecutive cold reads have produced the same shape of finding. Each time the crew fixed the named instance, the reader's fatigue migrated to the next device underneath it. The 2026-05-28 sweep named the beat-10 role-walk; the v4-detemplating spec consolidated it into ch-13. The 2026-05-29 sweep, reading the rebuilt book, named the next device down — the interception-channel scoreboard ("five / seven / eight channels," the asymmetry matrices) — plus a closing-image duplicate (Horizon-sub-postmaster / Therac-25-"P"-button across chs 7 and 9, now fixed).

The root cause is not a series of independent defects. The book is built on a small set of recurring **analytical devices**, and a cold cover-to-cover reader experiences their cumulative recurrence as fatigue — even when every individual instance is well made and every case is distinct. An instance hunt cannot terminate, because the devices are the book's pedagogy: it teaches one diagnostic and applies it thirteen times. The terminating move is to set a **finite frequency cap per device** — full strength once, compressed where the device still does distinct work, forbidden where it would only re-teach a lesson the reader already holds. The list of devices is closed; the per-chapter dispositions are designable; the work ends when the budget is met.
