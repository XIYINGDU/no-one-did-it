# Rule 05/07 hook pass — 2026-05-30

The pattern-based rule-05 (overclaim) and rule-07 (implication-burden)
hooks had been surfacing **87 warnings** across the 13 v6 chapters,
nearly all false positives caused by structural surfaces (chapter
titles, headings, table cells, footnote citations) and pattern
ambiguity (mechanical events flagged as causation, single-actor
narration flagged as chain-ladder).

After this pass: **0 warnings** across all 13 chapters. The path was
hook precision improvements (structural exemptions, semantic
tightening) plus a small number of targeted prose tightenings where
the original phrasing was load-bearing and genuinely strong.

## Hook refinements

### scan-overclaim.py

| Change | Rationale |
|---|---|
| Exempt YAML frontmatter | Slug fields (`chapter_id: 05-the-guilty-goat`) aren't prose claims |
| Exempt `# H1`–`###### H6` headings | Chapter and section titles using framework terms (`The Guilty Goat`) aren't assertions |
| Exempt `> block-quotes` | Rule 06 governs verbatim quotations |
| Exempt `\| table rows \|` | Visual summary cells; attribution adjacent |
| Exempt footnote definitions (`[^N]: ...`) | Footnote prose names court cases, plea agreements legitimately using rule-05 verbs |
| Recognise negation | `not guilty`, `does not declare anyone guilty`, `never deliberately` cleared via a 40-char window before each trigger |
| Recognise diagnostic question form | `*Who knew or should have known?*` (italicised) AND `Who knew or should have known?` (plain) treated as framework question, not assertion |
| Recognise procedural-stage citation forms | `pleaded guilty`, `was found guilty`, `guilty plea`, `jury found` — these ARE the rule-05 required citation form |
| Recognise court-attribution forms | `the Court of Appeal held`, `the District Court found`, `Judge X ruled` — proper citation |
| Recognise documentary-record framing | `the documentary record establishes/shows/documents X` |
| Recognise methodology framing | `ask, in writing,`, `question N`, `the diagnostic is`, `the question carries` |
| Widen agency-attribution pattern | `the DOJ Office of the Inspector General, in its January 2021 review, found...` (was tight; 110+ chars between agency name and verb now allowed) |
| Recognise Markdown footnote references | `[<sup>N</sup>](#cX-N)` and `[^N]` are the actual citation form in v6 prose |

### scan-implication.py

| Change | Rationale |
|---|---|
| Same structural exemptions | Headings / block-quotes / table rows / footnote definitions blanked with dot-padding (preserves line length AND paragraph identity) |
| Recognise diagnostic / hypothetical frames | `would attach`, `would point`, `would name`, `the diagnostic`, `the eight questions`, `the responsibility chain` — these are framework-as-instrument, not claims |
| Recognise rule-07 paradigmatic hedge | `convergence at the same actor`, `is a question for evidentiary discovery`, `the structural fact` — the explicit rule-07 hedge form |
| Recognise documentary backing | `the documentary record`, `on the public record`, `in the trial/court record`, `the trial/court/appellate opinion/judgment` |
| Tighten causation-by-adjacency verb set | Drop `following`, `after`, `prompted`, `triggered`. Keep `in response to`, `led to`, `because of`, `in light of`, `caused by`, `as a result of`, `in retaliation for`. Temporal `after` / mechanical `triggered` were ambiguous |
| Tighten engineering verb set | Drop `produced`, `set up`, `designed`, `constructed`, `arranged` (too common). Keep `engineered`, `orchestrated`, `manufactured`, `fabricated`, `architected`, `set the conditions for`, `stage-managed` |
| Tighten chain-ladder: require DISTINCT hierarchical verbs | `The Court directed... The Court directed...` (same verb twice from one actor) no longer fires. Real chain-ladders use varied verbs across actors |
| Recognise Markdown footnote references | Same as overclaim |

## What did NOT change

The hooks remain **warn-mode**, never block. The chapter-promotion gate
in `check-agent-frontmatter.py` is still the only deny path in the
project.

The hooks now reflect the v6 corpus's actual conventions:
- Footnote-bound prose with `[<sup>N</sup>](#cX-N)` references everywhere
- Diagnostic framework discussion in italic / plain question form
- Court-attribution prose with named courts, judges, and rulings
- Documentary-record framing as the chapter's standard backing
- Same-actor multi-instruction narration (Supreme Court ordering twice
  is still one actor, not a chain)

If the project changes citation conventions, the hooks need a matching
update. Specifically: if a future chapter is written without footnote
references and instead uses inline `[CITE: slug]` markers exclusively,
the existing `\[CITE:[^\]]+\]` pattern still catches them.
